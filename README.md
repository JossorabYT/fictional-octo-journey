# Phrase Phone 📖

Écrivez une histoire à plusieurs, chacun son tour. Le premier joueur invente le début; les suivants ne voient que la phrase précédente et ajoutent la suite. À la fin, découvrez toute l'histoire.

- Jouez à distance avec un code de salon
- De 2 à 12 joueurs
- Le premier joueur écrit l'ouverture
- Une seule phrase visible à la fois; l'histoire entière se révèle à la fin

Le backend Supabase est déjà configuré. Pour publier ce site, consultez [LISEZ-MOI.md](LISEZ-MOI.md).
