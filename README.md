# Phrase Phone 📖

Écrivez plusieurs histoires à distance. Chaque joueur invente un début en même temps; ensuite, les récits passent de main en main et chacun ajoute une phrase sans voir les autres histoires. À la fin, découvrez tous les récits.

- Jouez à distance avec un code de salon
- De 2 à 12 joueurs
- Chaque joueur lance une histoire
- Tout le monde écrit en même temps à chaque manche
- Chaque histoire passe aux autres joueurs avant la révélation finale
- Révélation finale en diaporama, une histoire par écran
- Lecture à voix haute des histoires pendant la révélation
- Choisis le thème jour ou nuit avec le bouton en haut à droite
- Le thème choisi est mémorisé sur ton appareil

Le logo Phrase Phone est créé pour le jeu et disponible dans `logo.svg`.

Le backend Supabase est configuré. Pour publier ce site, consultez [LISEZ-MOI.md](LISEZ-MOI.md).

## Jouer

Ouvre le site, crée un salon et partage le code ou le lien d'invitation. Chaque joueur rejoint avec son prénom. L'hôte lance quand tout le monde est là. Tous les joueurs écrivent leur début en même temps, puis une phrase à chaque manche. Les histoires restent secrètes jusqu'à la fin.

Chaque personne commence une histoire. À chaque manche, tout le monde écrit pour une histoire différente; chaque récit passe ainsi par tous les autres joueurs. Les salons se mettent à jour automatiquement toutes les 2,5 secondes.
